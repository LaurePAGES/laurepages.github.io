# Site Expert Copro Conseil

Site statique construit automatiquement par GitHub Pages (Jekyll).

- Modifier les textes : https://app.pagescms.org (connexion avec le compte GitHub), puis choisir ce dépôt.
- Les contenus modifiables sont dans `_data/` (services, tarifs, questions, coordonnées), `index.html` (haut de la page d'accueil), `a-propos.md` et `mentions-legales.md`.
- Ne pas supprimer : `CNAME` (créé par GitHub quand on ajoute le nom de domaine), `_layouts/`, `_includes/`, `assets/style.css`, `.pages.yml`.
- Après chaque enregistrement, le site se met à jour tout seul en 1 à 3 minutes.
